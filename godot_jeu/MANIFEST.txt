🕹️ CONTRÔLES
================================================================================

CLAVIER:
├─ Z ou Haut    → Avancer
├─ S ou Bas     → Reculer
├─ Q ou Gauche  → Tourner à gauche
├─ D ou Droite  → Tourner à droite
├─ Souris       → Regarder autour (maintenir clic-droit)
├─ E            → Interagir avec énigmes/boutons
├─ Espace       → Sauter
└─ Entrée       → Valider réponse d'énigme

MANETTE (optionnel):
├─ Stick Gauche  → Mouvement (ZQSD équivalent)
├─ Stick Droit   → Regard/Caméra
└─ Bouton X/□    → Interagir (E équivalent)

🎯 LES 3 ACTES
================================================================================

ACTE 1: LE BUREAU
- Durée: 1-2 minutes
- Condition d'accès: Aucune (libre d'entrée)
- Objectif: Trouver et cliquer le bouton rouge "Quitter Bureau"
- Description: Salle de bureau minimaliste - exploration libre
- Progression: Cliquer E sur le bouton → Acte 2

ACTE 2: SALLE AVENTURES
- Durée: 5-10 minutes
- Condition d'accès: Avoir quitté Bureau
- Objectif: Résoudre les 6 ÉNIGMES pour débloquer la sortie
- Description: Grande salle avec 6 buzzers colorés (cyan, vert, violet, etc.)
- 6 ÉNIGMES À RÉSOUDRE:
  1. "Quel pays manque à sa famille?" → netherlands
  2. "Premier grand projet qu'elle a mené?" → one ad conducteur
  3. "Quel autre projet majeur?" → le décrochage
  4. "Sa passion secrète?" → karaoke
  5. "Phrase culte pour briser les...?" → briser les glaçons
  6. "Mot 'interdit' qu'on adorait dire?" → bordel

- EASTER EGG: Taper "meme" comme réponse → 👑 MEME QUEEN FOR LIFE! 👑
  (Compte comme énigme résolue et déverrouille une réponse amusante)

- Progression: Résoudre 6/6 énigmes → Bouton devient vert/actif
               Cliquer E → Acte 3

ACTE 3: MUR DES MESSAGES
- Durée: 1-2 minutes
- Condition d'accès: Avoir résolu 6/6 énigmes dans Acte 2
- Objectif: Voir les messages d'adieu d'Apoorva
- Description: Affichage grand texte de tous les messages personnalisés
- Finale: 👑 MEME QUEEN 👑 - Célébration et fin du jeu

================================================================================
📊 DONNÉES - ENIGMES.JSON
================================================================================

Structure:
{
  "enigmes": [
    {
      "id": 1,
      "question": "Quel pays manque à sa famille?",
      "reponse": "netherlands",
      "indice": "Un pays avec des moulins et des tulipes",
      "type": "texte",
      "feedback": "C'est ça! Sa sœur vit aux Pays-Bas! 🇳🇱"
    },
    ... (5 autres énigmes)
  ]
}

Caractéristiques:
- Réponses insensibles à la casse (netherlands = NETHERLANDS = Netherlands)
- Réponses insensibles aux espaces (one ad conducteur = oneadconducteur)
- Chaque énigme a un ID unique (1-6)
- Chaque énigme a un indice en cas de mauvaise réponse
- Chaque énigme a un feedback de confirmation

================================================================================
📊 DONNÉES - MESSAGE.JSON
================================================================================

Structure:
{
  "messages": [
    {"auteur": "Alice", "texte": "Message d'adieu #1..."},
    {"auteur": "Bob", "texte": "Message d'adieu #2..."},
    ... (jusqu'à 10 messages)
  ]
}

Affichage:
- Tous les messages s'affichent dans Acte 3 (Mur des Messages)
- Chaque message occupe plusieurs lignes
- Les messages sont concaténés et affichés en grand texte

================================================================================
📦 BUILD & EXPORT - WINDOWS .EXE
================================================================================

PRÉREQUIS À L'EXPORT:
- Godot 4.6+ doit être installé et le projet ouvert
- Tous les fichiers doivent compiler (F12 pour vérifier)
- enigmes.json et message.json doivent être présents
- Musique MP3 doit être présente

ÉTAPES D'EXPORT:
1. Depuis Godot: Project → Export... (Ctrl+Alt+E)
2. Ajouter preset si absent: Add Preset → Windows Desktop
3. Configurer: Export Path = ../Jeu_Adieu_Apoorva.exe
4. Cliquer "Export Project"
5. Choisir dossier de destination
6. Attendre 30-60 secondes

RÉSULTAT:
- Jeu_Adieu_Apoorva.exe (l'exécutable)
- Jeu_Adieu_Apoorva.exe.folder/ (les assets/données)
  [IMPORTANT: Garder ce dossier avec le .exe!]

DISTRIBUTION:
- Zipper le dossier entier
- Partager le .zip
- L'utilisateur dézippe et double-clic sur .exe

================================================================================
🐛 TROUBLESHOOTING RAPIDE
================================================================================

PROBLÈME: Scripts ne compilent pas
→ F12 pour voir les erreurs
→ Chercher les lignes rouges
→ Corriger et relancer

PROBLÈME: Pas de musique au démarrage
→ Vérifier: assets/audio/Sabrina Carpenter - Espresso*.mp3 existe
→ Vérifier: MusicManager est dans scène Menu
→ Consulter: TROUBLESHOOTING.md

PROBLÈME: Énigmes ne s'affichent pas
→ Vérifier: enigmes.json est présent et valide
→ Vérifier: GameManager est dans scène SalleAventures
→ Vérifier: UIManager existe avec tous les éléments
→ Consulter: TROUBLESHOOTING.md

PROBLÈME: Bouton "Accès Mur des Messages" grisé
→ Normal! Résoudre d'abord les 6/6 énigmes
→ Vérifier le compteur (X/6) en bas à gauche
→ Après 6/6, attendre 2 secondes et réessayer

PROBLÈME: .exe lance mais manque ressources
→ Vérifier que le dossier .exe.folder/ est présent
→ Vérifier que enigmes.json et message.json y sont
→ Consulter: BUILD.md section Troubleshooting

================================================================================
📝 PERSONNALISATION
================================================================================

AJOUTER DES ÉNIGMES:
1. Éditer assets/data/enigmes.json
2. Ajouter un nouvel objet dans le tableau "enigmes"
3. Incrémenter l'ID (id: 7, 8, etc.)
4. Sauvegarder et relancer

MODIFIER LES MESSAGES:
1. Éditer assets/data/message.json
2. Modifier ou ajouter des messages
3. Chaque message: {"auteur": "...", "texte": "..."}
4. Sauvegarder et relancer

CHANGER LA MUSIQUE:
1. Remplacer le fichier: assets/audio/*.mp3
2. Ou éditer music_manager.gd et changer le chemin
3. Les formats supportés: .mp3, .ogg, .wav

AJOUTER DES IMAGES:
1. Copier dans: assets/images/
2. Les images existent mais ne sont pas encore intégrées dans le jeu
3. Feature future: affichage galerie photos dans Acte 3
